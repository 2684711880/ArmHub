# 位置触发的夹爪加力辅助

保留官方六轴轨迹、重力前馈和夹爪位置环；在指定的闭合阶段额外叠加负方向前馈力矩。降低原始电机角度为闭合方向。本功能不判断物块已抓稳，不是夹指力传感闭环，也不需要改写已录数据。

## 本轮蓝块试录

`local/blue_pick_trial_01` 第 0 回合：602 帧、20 FPS，约 10–15 秒夹爪开度稳定在 0.78 rad，张开阶段约 1.5–1.65 rad。首帧约 0.025 rad，不能在启动时根据“小开度”直接加力。

```bash
cd /home/a/ArmHub
bash scripts/lerobot.sh prepare --execute
bash scripts/lerobot.sh replay --repo-id local/blue_pick_trial_01 \
  --episode 0 --execute --gripper-assist 0.1
```

这是实机运动命令。0.1 是本次小力矩试验起点，单位为原生 SDK 电机侧 Nm；不是已验证的夹持效果，也不是指尖牛顿数。软件允许附加力矩 (0,0.3] Nm，不要把上限当作推荐值。

普通 `replay` 没有此辅助，添加 `--gripper-assist` 才启用。其他数据集必须显式传 `--gripper-close-at` 指定自己的加力开度阈值，本轮默认 0.85 rad 不自动套用其他任务。

## 触发与撤销

1. 先看到目标和实际夹爪已张开到约 1.2 rad，才允许一次闭合辅助。初始闭合帧不加力。
2. 之后目标进入 <=0.85 rad、实际位置与目标相差 <=0.08 rad，实际速度 <=0.2 rad/s，开始辅助。
3. 在 0.3 秒内将附加力矩从零增加到 -0.1 Nm。保留夹爪 `Kp=4.5`、`Kd=0.45`；位置目标增加下述限速和位置误差约束。
4. 目标比这次闭合过程中的最小目标增大 >=0.08 rad 时立即撤销辅助，过滤细小示教抖动。这次部分张开后要再次充分张开，才允许下一次闭合加力。
5. 目标或实际开度 <=0.1 rad 时停止辅助，防止在空夹机械终点持续施加额外力矩。辅助期间位置误差 >0.2 rad、反馈故障/过期/未更新、控制间隔 >0.25 秒或反馈力矩绝对值 >1 SDK Nm 时抛错，沿用官方回放的 finally 退出保持。

附加前馈力矩有界，但总电机力矩还包括原位置环和阻尼项；1 Nm 是主机采样后的软件保护阈值，不是固件瞬时硬限幅。回放结束、Ctrl+C 或异常退出后，原退出流程按新实测位置保持，不继续永久发送本次附加力矩，也不自动开爪。

## 数据与实现

自动记录 `logs/lerobot/gripper/replay_<时间>.csv` 和摘要，包含夹爪开度、速度、反馈力矩、辅助状态与请求前馈力矩。后续根据实际结果再调小力矩，不宣称能识别滑落或区分物块与卡住。

运行时仅代理官方发送线程里的 ID 7 五参数命令，在同一帧叠加前馈；六轴命令不改，没有混用位置限力协议或开第二个 SDK 会话。每帧 finally 恢复原电机对象。原函数吞掉的夹爪命令异常也会重新抛出并进入退出保持。

`tests/test_gripper_assist.py` 包含实际官方 send_action 的七电机命令测试、初始闭合拒绝、接近与速度条件、渐增力矩、部分张开释放、机械终点、异常反馈和周期保护。录制目标序列的离线演算假定实测位置跟随目标，只证明触发区间，不等于实物夹持验证。

## 启动跳变修复

用户报错与首轮空日志确认辅助开始前的力矩反馈已超过 1 Nm，保护未放宽。源码回归复现了另一个启动缺陷：官方空闲保持从只含六轴的 get_current_pos() 构造七轴目标，夹爪曾被补成零。补丁改用 get_current_pos_gripper() 的实测开度，保留正确的七轴位置保持。

启用辅助回放时，夹爪第一条位置命令锚定新实测开度，之后目标变化率最多 0.3 rad/s；位置命令与实测开度相差不超过 0.08 rad。若限速与误差约束无法同时满足则停止，禁止通过大位置误差追赶录制跳变。只有限速后的目标也接近录制夹持目标时才叠加力矩。CSV 新增 limited_position_target_rad，记录实际下发的位置目标；异常摘要新增 failure，保留首次失败原因和反馈力矩数值。

prepare --execute 现明确执行“六轴回到原准备位→夹爪按 0.3 rad/s、0.3 Nm 上限张开到 1.6 rad→新反馈确认完成”，不再保留闭合开度作为准备状态。上述数值读取原教学配置，不改写已有准备位。
