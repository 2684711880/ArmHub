# 50 条成功示教：人工保留与失败重录

退出其他机械臂/相机程序，从交互终端启动：

```bash
cd /home/a/ArmHub
bash scripts/lerobot.sh record --review \
  --repo-id local/blue_to_box_clean_01 --execute
```

默认累计到 50 条成功数据，无回合时限，自动识别已有完整回合并续采；无需手动切换 resume。若只想先试 5 条，可追加 `-- --dataset.num_episodes=5`，之后正常启动同一数据集会继续累计到 50。

## 每轮操作

1. 首次启动按提示回车，执行“回准备位并开爪”。
2. 固定盒子，把蓝块摆好；手离开画面，终端输入小写 n 并回车开始录制。已在准备位后只需这一个开始键。
3. 终端显示“正在录制第 k/50 条，已成功保留 j 条”。失败重录仍为第 k 条，不增加成功数量。
4. 抓取蓝块、放入盒子、松爪，夹爪竖直抬离盒口并停稳后按 → 结束录制。停在盒子上方即可，回准备位不录进去。
5. 等待保持完成后，在终端输入字母并回车：
   - s：成功，先保存数据，再回准备位并开爪；最后一条保存后也会回准备位。
   - r：失败，清掉当前未保存回合，不计数，回准备位并开爪。
   - q：丢弃当前未保存回合并退出，已有成功数据保留。
6. 到位后等待 n，不会自动开录。摆好下一轮蓝块，输入 n 并回车即可。

不要把“抓空、掉落、放到盒外”保留为成功。回车本身不会默认保留，也不会代替 n 开始录制。左方向键 ← 可标记本轮重录，结束后仍需经过下一轮的准备和开始确认，不会立即偷偷开录。

少于 5 帧不能保留。Esc 请求结束本次采集，之后若选 s 会保留本轮并回准备位后退出；r 明确选择重录后继续，q 丢弃并退出。Ctrl+C 或 EOF 不会默认保留未确认回合。程序错误与动作失败不同：报错时不自动接着运动，应先核对原因。

## 文件与退出

- 成功数据为标准官方 LeRobot 数据集：`datasets/lerobot/local/blue_to_box_clean_01`。
- 决策流水：数据集根目录的 `manual_review.jsonl`。
- 中途退出后原命令再次运行，累计已有成功回合，目标仍是总计 50 条。
- 首轮尚未成功保存而中断留下的零回合目录，会完整改名保留为 `.empty-<时间>` 后新建，不会直接删除恢复材料。
- 当前旧的 `local/blue_to_box_01` 两个回合保持原样，不自动当作已确认成功的数据迁移。
- s 保存完成后才回准备位；若回位报错，已保存的数据仍保留，停止继续开录。每轮结束后先停止官方发送线程、用新反馈确认保持，再关闭串口和相机。回准备位复用现有 HardwareSession，之后才重新连接采集，避免两个 SDK 同时占用硬件。

这个审阅开关仅用于单臂手动示教。未加 `--review` 的官方采集流程不变。当前采集仍使用官方夹爪位置示教，回放/后续策略执行时需另行启用所需夹持辅助。

## 验证

`tests/test_manual_review.py` 通过真实官方 record 函数配合合成机器人检查成功追加、失败不计数、退出不自动保存和累计目标；另使用真实 LeRobotDataset 验证拒绝后保留两轮、保存、追加及视频重新解码。软件验收不等于实机连续采集验证。

## 输入线程

终端字母由独立的 lerobot-terminal-keys 线程读取，经有阶段编号的队列交给主流程；主控制路径不直接调用 input()。原来的方向键监听仍负责 →/←/Esc。字母需要回车确认。

输入线程在切换准备、开始和审阅阶段时清理旧字符；录制或回位期间误输入的 s/n，以及未回车的残留字符，不会自动触发下一个阶段。等待输入使用短间隔轮询，退出可唤醒等待并结束读键线程；读键线程不调用任何机械臂 API。决策输入前仍先完成已验证的保持和串口交接。

### 持续相机预览

`--review` 默认开启 Rerun 实时预览。D435 在启动后持续连接，等待 `n`、审阅 `s/r`、保存和回准备位时都可看画面摆蓝块；只有输入 `n` 后的录制阶段才写入回合。退出程序时释放相机。预览与采集共用一个相机连接和最新帧缓存，后台线程读取，不阻塞按键输入；相机失联或图像过期会拒绝开始新回合和继续采集。

相机读取与 Rerun 发送分属两个线程，显示异常或阻塞不再停止相机读取。短暂无帧时持续尝试读取，恢复后继续预览；没有新鲜帧时拒绝采集。`logs/lerobot/camera/d435.json` 每秒记录时间、已读取帧数、已发送帧数、帧龄和错误，便于区分相机停帧与显示停更。该文件是诊断状态，不是训练数据。
